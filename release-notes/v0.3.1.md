# v0.3.1 · 两条静默失效 + Windows 真机验证

> 这个版本已发过 Release，正文可直接沿用；这里补一份更细的清单。

### 修复

- **世界书注入的消息补 `id`** —— 缺它会让会话历史**永久打不开**
  （`session event at seq N lacks an identified message`）（`c46dabc`）
- **CRLF 检出下整份世界书静默失效**：Windows 上 `core.autocrlf=true` 检出为 CRLF，
  解析层只按 `
` 切行 → 每个字段尾部带 `\r`、触发词永远匹配不上。
  解析层吞掉 CRLF + `.gitattributes` 加 `* text=auto eol=lf`（`c225499`、`23b9f31`）
- **`cyrene-work` 在起不来 `workflowEngine` 的部署上整条预设判「加载失败」**：
  默认关闭依赖它的三行（代价是少三个工具 ≪ 整条预设不可用）（`ddbb66d`）
- 声明导出漏了 `- insert:` 那层（按字面用会静默失效）（`61039b4`）
- 入口判断 `import.meta.url === file://${argv[1]}` 在 Windows 上永不成立 → CLI 静默零输出（`380e250`）
- 预设测试在无 DSH 环境下崩溃，导致 CI 两次 job 全红（`bdf726c`）
- `LICENSE` 恢复为逐字标准 MIT，让 GitHub 能识别（`0804b5d`）

### 新增

- **支持 DSH 0.2.0+ 的声明式预设注册**（旧版目录方式在那一代静默失效）（`53b348d`）
- **CI 增加真实 `windows-latest` job**；维护边界写进 README / `CONTRIBUTING.md`（`9f6a769`）
- `docs/windows.md`：六条实测坑 + 为什么没有 `install.ps1`（`131b1ec`、`23b9f31`）
- 工作模式压制追问，避免靠反问收尾（`2987438`）

### 移除

- **删除 `install.ps1` / `install.bat`**：作者没有电脑、无法实测，连试三轮仍未在真机跑通
  （`b3cc7f0`、`fa05aa1`、`4706529`）
