# v0.5.0 —— 称呼会变、世界书能改、安装少一步

> 上一次发版是 **v0.4.0**。这一版把几件"用起来别扭"的事收干净了：
> 称呼能改了、世界书配置能热更新了、0.2.0+ 的预设不用手贴声明了。

## 称呼是动态的

`{{user_nickname}}` 本来就是每轮现取，这一版补上**对话中改口**的两条路：

- **显式**：「以后叫我小明」「称呼改成老师」→ 插件自己解析并落盘，不依赖模型自觉，
  本轮就用新名字；
- **暗示**：「我们之间还用这么生分吗」→ 模型判断后调 `set_nickname` 工具。

三条来源（设置里的自定义名称、显式改口、模型改口）写的是**同一个文件**
`<DSH_HOME>/dsha-brand-rename.json`，读-改-写，不会各记一套。

还有**关系称呼**：求婚后那句「那是不是得叫那个啦，老婆？」会被理解成「你该叫他老公」——
`nickname.js` 每轮注入一条 `order: 120` 的规则，写明老婆 ↔ 老公要推回对应那一个。
光有变量推不动，模型会一直用旧名字。

刻意的取舍：否定句（「别再叫我先生」）和问句（「你叫我什么」）不解析；
插件自己注入的消息不算用户输入。

## 世界书：配置归一化 + 改完立即生效

- 配置不再裸合并：类型写错退回默认（`"enabled": "false"` 这种字符串以前因为真值判断
  等于**开着**），数值夹到区间（`scanDepth` 1–5、`maxActive` 1–50）。
  `null` 也不会再被 `Number()` 强转成 0。
- 条目缓存从「固定 30 秒 TTL」改成**目录签名**（文件名 + mtime + size）：
  改了 `.md` 下一轮就换，不用等、不用重启。
- 新增 `npm run wb:audit`：按 SillyTavern 世界书的写法口径给随包数据打分。

## 安装：0.2.0+ 不用再手贴声明

`scripts/install.mjs` 会自动判断 profile 属于哪一代：有 `@deepseek-ai/dsh-agent-preset`
的就把两套预设声明写进该 profile 的 `cordis.patch.yml`（先备份、幂等、只追加），
同时仍给 0.1.x 写目录副本。为什么不像衍生版那样塞进本包的补丁文件：那一行在 0.1.x 上
解析不到，实测会让 DSH 起不来（`ERR_MODULE_NOT_FOUND`）。

## 其它

- 会话格式对齐 v4：插件注入的消息必须带 `plugin:<id>` 形式的 `source.kind`，
  裸 `plugin` 会直接 `SessionFormatError`。
- 修了 Windows 检出（CRLF）会把世界书整份静默失效的问题 —— 解析层吞掉 `\r`，
  外加 `.gitattributes` 强制 LF。
- 单元测试 74 → **146** 条，CI 覆盖 ubuntu 22/24 与 **windows-latest**。
