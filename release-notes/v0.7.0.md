# v0.7.0 —— 角色扮演模式：从「括号自动触发」改成设置里的开关

> 上一次发版是 **v0.6.0**。这一版只动一件事：**什么时候进入角色扮演，由你说了算**。

## 改名

「角色扮演场景」→ **「角色扮演模式」**。

## 开关在设置里

**设置 → 通用 → 角色扮演模式**，一个开关，默认关。

- 打开：所有走纯文本对话模式的会话都按角色扮演回复；
- 关掉：回到平常聊天，一个字都不注入；
- 状态存 `<DSH_HOME>/cyrene-scene.json`，手改也生效。

以前是"这一轮消息里有没有括号"来决定切不切场景：想演的时候得**每轮都带括号**，
忘了就掉回平常聊天，而且"开 / 关"的标记消息会进会话历史。现在这两件事都没有了。

## 开着的时候，每轮必须有三样

1. **场景描述** —— 光线、温度、气味、周围的动静；
2. **角色动作描述** —— 她这一轮做了什么，写在括号里，对象称「你」；
3. **角色外貌描述** —— 形态、衣着、发丝、眼神、表情的变化，每轮换一个焦点。

同时写清的约束：台词仍是主体、三样各一两句、别写成小说；用「（…）」给的场景或动作
**是照做的指令**（不复述原句、不问"要不要这样做"）；不出戏、不提"角色扮演模式"。

## 形态切换还在

`（你变成迷迷）`、`切换成大昔涟`、`变回小昔涟`、`恢复原来的样子` 照旧；
暗示（`变小一点好不好`）仍由 `set_form` 工具处理。形态按会话记，重启回到默认。

## 升级

```bash
npm install -g dsh-cyrene@0.7.0
node <包目录>/scripts/install.mjs   # 重装预设
```

⚠️ **这一版多了一个浏览器半边**（设置里那一行）。如果你是把本仓库 `link:` 进 profile 用
的，重启一次 App 让它加载；没有浏览器半边的部署里，预设本身照常能跑，只是没有设置页，
可以直接改 `cyrene-scene.json`。

## 测试

174 → **180** 条。新增覆盖：开关状态的默认值 / 坏文件 / 非布尔值、TTL + mtime 缓存、
注入块的三样要求、开关不再往历史里插消息、`/cyrene-scene-api` 的 GET/POST 与各类拒绝。
