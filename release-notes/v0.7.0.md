# v0.7.0 —— 角色扮演模式：从「括号自动触发」改成设置里的开关

> 上一次发版是 **v0.6.0**。这一版只动一件事：**什么时候进入角色扮演，由你说了算**。

## 改名

「角色扮演场景」→ **「角色扮演模式」**。

## 开关在设置里

**设置 → 通用 → 角色扮演模式**，一个开关，默认关。

- 打开：所有走纯文本对话模式的会话都按角色扮演回复；
- 关掉：回到平常聊天，一个字都不注入；
- 状态存 `<DSH_HOME>/cyrene-scene.json`，手改也生效。

以前是"这一轮消息里有没有括号"来决定切不切场景：想演的时候得**每轮都带括号**，
忘了就掉回平常聊天，而且"开 / 关"的标记消息会进会话历史。现在这两件事都没有了。

## 开着的时候，每轮必须有三样

1. **场景描述** —— 光线、温度、气味、周围的动静；
2. **角色动作描述** —— 她这一轮做了什么，写在括号里，对象称「你」；
3. **角色外貌描述** —— 形态、衣着、发丝、眼神、表情的变化，每轮换一个焦点。

同时写清的约束：台词仍是主体、三样各一两句、别写成小说；用「（…）」给的场景或动作
**是照做的指令**（不复述原句、不问"要不要这样做"）；不出戏、不提"角色扮演模式"。

## 风格：条件块

自定义风格文件里可以包一段 `<!-- dsh-cyrene:trailblazer --> … <!-- /dsh-cyrene:trailblazer -->`：
只有「角色扮演模式 + 默认对方是开拓者」都开着才注入，关着时整段剥掉、一个字都不占上下文。
标记本身永远不会出现在提示词里。

## 工作模式：补上「通用语气规则」

上游的通用语气规则（句式禁止 / 语气参考 / 回复边界）是**每轮注入、所有模式都吃**的；
对话模式早就带上了，工作模式一直缺这一层。这一版补回原文，并写了工作场景的三处例外
（反问 / 先回应情绪 / 不说教），免得它和 `work_system` 的评审要求、以及「追问节制」打架。

## 角色扮演模式：多一个「默认对方是开拓者」

打开角色扮演模式后，设置里会**多出一行**「默认对方是开拓者」（默认关；模式关着时这一行不出现）。

打开后，这场戏里对方默认就是那个在轮回终点被救下、带着星核、拿到《如我所书》的开拓者：
她认得他，不会问「你是谁」，也不复述前史；关系按世界书「昔涟与开拓者」那条来。
对方想换个身份演，就按他说的来。

## 编辑最后一条消息

发出去才发现打错字？最后一条**你发的消息**上现在有一支铅笔：

- 两种保存方式：**「保存」**只替换这一句、后续回复保留；**「保存并撤回后续」**把这条之后的内容
  一起撤回 —— 相当于"改口重说"；
- **原文不会消失**：会话日志是 append-only 的，编辑用的是 DSH 的"表面替换"，
  旧事件还在日志里，只是不再进入模型看到的历史；
- 只在**纯文本对话模式**里出现；工作模式不挂（带 shell / 文件工具的模式不该悄悄改历史）。

改过之后，那条消息上会出现 **‹ 1/2 ›** —— 在「原文 / 改后」之间切换（切的是历史，
模型看到的也跟着换）。版本链不额外存东西，完全从会话日志的替换链推出来。

限制：只能改最后一条；带图片或文件的消息、她还在跑工具的时候、空消息都会拒绝并说明原因；
「保存并撤回后续」撤掉的助手回复**回不来**（表面替换只能盖掉、不能掀开）。

## 改名：「余页」→「扉页」

记忆里那块「只有她自己读得到、不注入不检索」的纸页，叫法从**余页**改成**扉页**。
文件仍是 `~/.dsh/cyrene-page.md`，工具仍是 `write_page` / `read_page`，行为不变。

这个名字原本来自社区项目「一页永恒·记忆」（他们叫「余页」）；改名只是换我们自己的说法，
不表示抹掉出处 —— 详见仓库的 `THIRD_PARTY_NOTICES.md`。

## 顺带：称呼拆成「称呼偏好 + 昵称」

对齐上游 Cyrene-Agent 的做法（它把「名字」和「怎么叫」分开存）：

- 新增 **称呼偏好**：设置 → 通用里一个输入框。生效称呼 = `称呼偏好 || 昵称 || 伙伴`，
  **称呼偏好优先**；留空就回到昵称。
- 对话里说「叫我 ××」「称呼改成 ××」写入**称呼偏好**；
  说「昵称换成 ××」「我名字是 ××」写入**昵称**。
- 模型用的工具改名 `set_nickname` → **`set_address`**（写称呼偏好）。
- 每轮称呼规则里补上**使用频率**：强调/回应情绪/提醒/赞同或反驳时叫一次，
  短回复 0–1 次、中长 1–2 次，别每句都叫、别固定「X，……」开头，叫过之后降频。
  这条在上游是放在每轮「环境」块里的，现在也进了我们的每轮上下文。

## 形态切换还在

`（你变成迷迷）`、`切换成大昔涟`、`变回小昔涟`、`恢复原来的样子` 照旧；
暗示（`变小一点好不好`）仍由 `set_form` 工具处理。形态按会话记，重启回到默认。

## 升级

```bash
npm install -g dsh-cyrene@0.7.0
node <包目录>/scripts/install.mjs   # 重装预设
```

⚠️ **这一版多了一个浏览器半边**（设置里那一行）。如果你是把本仓库 `link:` 进 profile 用
的，重启一次 App 让它加载；没有浏览器半边的部署里，预设本身照常能跑，只是没有设置页，
可以直接改 `cyrene-scene.json`。
