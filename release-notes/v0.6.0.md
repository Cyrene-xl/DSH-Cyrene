# v0.6.0 —— 记忆分层 + 余页，世界书不再一口吃满

> 上一次发版是 **v0.5.0**。这一版只做一件事：**别让她一直背着不该背的东西**。
> 记忆侧多出「锚点 / 归档 / 余页」，世界书侧多了「门槛词 + 单条截断」。
> 升级不用改任何文件，老配置老记忆都照常能读。

## 记忆：三层结构

同一份 `~/.dsh/cyrene-memory.md`，越靠前越"骨"：

| 层 | 长什么样 | 注入吗 |
| --- | --- | --- |
| 四问锚点 | `## 我是谁` / `## 你是谁` / `## 来处` / `## 去处` | ✅ 排在最前 |
| 记忆条目 | `- 一行一条` | ✅ 锚点之后 |
| 归档 | `## 归档（不注入）` 以下 | ❌ 留在文件里，不进上下文 |

- 锚点由 `set_anchor` 维护 —— 回答"这段关系走到哪了"，不是流水账。
  缺哪节补哪节，永远按四节顺序排；不会因为后面攒了几百条记忆就被挤到下面。
- **归档**是"舍不得删、又不用她一直记着"：挪到那行标记下面就行，文件里还在、你随时能翻。
  想真删还是 `forget`。

## 余页：她自己的纸页

`~/.dsh/cyrene-page.md` —— `write_page` 写、`read_page` 读，按天分组，单条 ≤500 字、
整页 ≤64 KB。**不注入、不检索**：你不问，它就不出现。

写的是"不想让你看见的、还没想明白的、只想留个痕迹的"。当然它就是个普通 md 文件，
你也能自己打开。

## 不再播报

`remember` / `set_anchor` / `write_page` 三个工具的说明里都写明了「不要向对方播报」。
她不会回你一句「我记住了」，只会接着说话 —— 记忆是背景，不是新闻。

## 世界书：门槛词与单条截断

- **`必须同时命中`**（本项目扩展字段）：`- 必须同时命中: 黄金裔, 发小` 要求这些词
  **全部**出现才算命中。单说一个「白厄」不会再拉进整篇人物志；门槛词可以跨轮命中。
- **单条截断 `entryMaxChars`（默认 320）**：长条目注入时按句号边界截短、末尾加 `…`，
  **文件本身不动**。想要上游原文：`{"entryMaxChars": 0}`。
- 截断**先于**预算计算 —— 一条 800 字的条目不会按 800 字占预算、截完却只剩 320 字，
  把本该进来的第二条挤掉。
- 实测：最坏情况注入从 3300 字符 ≈ 1980 token → **2902 字符 ≈ 1741 token**，
  `maxChars=1600` 再兜一层。

## 体检工具订正

- 「正文以标题开头」**不再报成问题** —— 解析器本来就剥掉了标题行，正文开篇自报名字
  是推荐写法（截断后仍认得出是谁）。
- 「触发词过短」拆开：专名（白厄、缇宝）两三个字很正常，不报；只报**停用词**
  （`我` / `你` / `用户`）挂在非常驻条目上 —— 那等于把那条变成常驻。
- `--strict` 进了 CI（ubuntu + windows），数据回归会直接把 CI 打红。

## 升级

```bash
# 插件本体
npm install -g dsh-cyrene@0.6.0     # 或者按 README 的本地路径装法
# 然后照旧跑一次预设安装
node <包目录>/scripts/install.mjs
```

- 老记忆文件**不用改**：不加锚点照样能读，只有 `set_anchor` 才会长出锚点。
- 老世界书配置**不用改**：不写 `entryMaxChars` 就是默认 320。
- 余页是新文件，不存在就不创建 —— 第一次 `write_page` 才建。
