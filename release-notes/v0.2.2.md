# v0.2.2 · 世界书随包发运

### 新增

- **61 条世界书随包发运**（`worldbook/data/`），按触发词自动注入；装了就有，不需要自备（`78cd969`）
- 注入通道按「需不需要本轮消息」拆成两条：
  - 常驻块（内容恒定）→ `systemPrompt.context()`，只落库一次
  - 命中块（需要本轮消息）→ `agent/pre-step`

### 修复

- 绕开一个**静默失效**：`assemble()` 跑在用户消息落库之前，装配期读会话永远拿不到本轮输入
  （新会话第一轮更是一条都没有）；空文本 section 会被过滤掉，快照里看不出异常

### 说明

- 条目格式与字段语义来自 Cyrene-Agent 的 `rag/worldbook.ts`，本项目的匹配器是其简化实现
  （去掉 DMAE 状态机，故「内在价值」不生效、「优先级」成为主排序键）
