# v0.7.4 —— 装得上、有护栏：0.2.x 安装器与抄本漂移修复

> 上一次 GitHub Release 是 **v0.6.0**。这个 Release 覆盖 v0.7.0 到 v0.7.4 的全部改动；
> 逐版本细节见 [`CHANGELOG.md`](../CHANGELOG.md)。

## 这一版修了什么

一份外部审查清单指出四条「不报错、静默失效」的问题，本轮全部修掉：

### 1. 0.2.x 上安装器不再静默不注册

0.2.0+ 的内置包走全局解析，profile 的 `node_modules` 里没有
`@deepseek-ai/dsh-agent-preset` —— 旧版安装器据此误判成 0.1.x，只往
`.agent-presets/` 拷目录（0.2.x 已无人读取），然后打印「安装成功」。

现在：

- 代际探测走 `DSH_INSTALL` → `dsh --version` → 全局安装路径；
- 探测不到时**打印显式警告**并给出修复命令，不再静默降级；
- 可以用 `--generation=legacy|declarative`（或 `DSH_GENERATION`）显式指定；
- profile 补丁里的声明块按内容比对，预设文本更新后会整块替换。

### 2. 抄本漂移护栏在 0.2.x 恢复工作

`tests/preset.test.mjs` 原来按 0.1.x 的包布局解析内置 standard，0.2.x 上整组跳过
（正好是护栏该管的那一代）。现在同时支持 0.2.x 的 `presets/standard.patch.yml`，
并补上了 `cyrene-work` 缺失的 `time-context`、`tool-schedule`、`workflow-ptc`
（后者与其它 workflow 行一样默认 disabled），`tool-plugin-manager` /
`tool-plugin-market` 与上游对齐为 disabled。

测试现在是 **239 条、0 失败、0 跳过**。

### 3. 文档残留

测试条数不再写死、加载日志不再提已删除的 `install.ps1` / `install.bat`、
删掉一段挂错位置的注释块。

## 安装

```bash
git clone https://github.com/Cyrene-xl/DSH-Cyrene
cd DSH-Cyrene
node scripts/install.mjs --dry-run     # 先看计划
node scripts/install.mjs --yes         # 安装
```

需要 Node 22+、DSH 0.1.5 或 0.2.1（`engines`：`>=0.1.0 <0.3.0`）。
