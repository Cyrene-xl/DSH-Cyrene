# v0.7.6 —— 剧情推进 + 手动检查更新

> 上一个 Release 是 **v0.7.4**。这一版两个改动：角色扮演模式要求「每轮推进」，
> 设置里新增手动的「检查更新」。

## 角色扮演模式：剧情推进变成硬性要求（v0.7.5）

以前只要求每轮写场景 / 动作 / 外貌，容易出现「描写很漂亮但局面原地不动」。现在注入块里多了一段：

- 每一轮局面**至少前进一小步**（地点、时间、氛围、距离、关系、信息、手里的东西）；
- 必须**主动递出下一轮的钩子**：刚发生的小事、需要回应的问话、可选的方向；
- 允许她主动行动，不必每轮等你下指令；
- 你带方向时跟随补细节，不抢主导权；
- 信息一点点给，不一次交代完，也不连续两轮抛同类型的新东西。

## 检查更新（v0.7.6）

设置 → 通用 → **检查更新**：

- 只读本地版本、不联网；点按钮才查询 GitHub `releases/latest`；
- 显示当前版本 / 是否最新 / 新版号与 Release 链接；
- 宿主 24 小时缓存 + ETag、6 秒超时，失败只在行内显示原因；
- **只查不装**：`link:` 安装，更新仍是仓库目录里 `git pull`。

## 升级

```bash
cd /root/dsh-cyrene
git pull
# 预设文本有更新时：
node scripts/install.mjs --yes
# 然后重启 App
```

需要 Node 22+、DSH 0.1.5 ~ 0.2.1。
