# v0.2.3 · 外部评价 P0–P3

逐条核实外部评价后处理，另外修了他没提到的两处。

### 修复

- **P0 人设正文的硬规则冲突**：正文同时写着「这些词语并非绝对禁止」与「不可以使用……」，
  以及「对方要求解释时必须说明」与「不需要解释为什么」。根因是上游靠**请求尾部注入的时序**
  压过正文，本仓库合并成静态正文后时序消失。
  修法是把**覆盖关系显式写回正文**（定向覆盖 + 一处明确例外），而不是删改上游文本（`bb3b9e0`）
- **P1 记忆通道没有净化**：`memory.js` 原样塞进系统提示词，而记忆的写入方是模型、触发源可能是
  联网结果。现在写入与注入两处都清洗，整份记忆包进显式数据分隔块（`bb3b9e0`）
- **P2 CI 与测试命令**：测试头部那条 `node --test tests/` 会挂；已改正并加警告。
  新增 `package.json` 的 `test` 脚本、`harness:check` 扩到全部运行时代码、
  新增 `.github/workflows/test.yml`（Node 22/24，无需 npm install）
- **P2 人设残留痕**：删除上游自带的空台词行与一段逐字重复的「知识性回复」，
  保留 `#` 标题作来源锚点，并在 `THIRD_PARTY_NOTICES` 如实披露
- **P3 六个小口子**：`forget` 只删 `- ` 开头的条目行（短关键词不再误删标题）；
  `scanDepth` 1–5 真的生效（原先被静默夹到 3）；`lastHit` 改有界 LRU（上限 64 会话）；
  删死代码 `assembleSplit()`；`index.js` 版本号改为读 `package.json`
